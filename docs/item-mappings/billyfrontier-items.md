## Notes

1. Billy’s plant family is area-dependent: Town and Swamp share the same item type but not the same model family.
2. `DeadTree` uses `p0` for rotation and `p1` for variant; those meanings must not be swapped.
3. `WoodCrate` contents live in `p2`.
4. `Post` only implements `p0 == 0`; other values remain unresolved in source. Source: `games/billyfrontier/Source/Items/Items.c:952-981`.
