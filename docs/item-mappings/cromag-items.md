## Notes

1. Cro-Mag item meshes are heavily track-dependent. `Tree`, `Pillar`, `Statue`, and `House` must key off track context.
2. `Waterfall` is a real dispatch slot but its spawning code is compiled out and the function just returns true. Source: `games/cromagrally/Source/Terrain/Liquids.c:225-312`.
3. `CastleTower` uses `p0` for both subtype and rotation; `p1` is unused. Source: `games/cromagrally/Source/Items/Items.c:1166-1209`.
4. The flags enum has a quirk: `ITEM_FLAGS_USER1` and `ITEM_FLAGS_USER2` are both defined as `(1<<1)`, and no audited route reads either bit. Source: `games/cromagrally/Source/Headers/terrain.h:127-132`.
